# M8 Kindle Checklist

**NOT APPLICABLE** - M8 evaluates the server-side user lookup and friendship
primitives plus their Android network-client contract. The interactive friends
screen and device-visible acceptance are assigned to later milestones, so an
APK installation would not add required M8 evidence.

or emulator was connected at the final checkpoint verification. Because device
testing is not applicable to M8, this does not prevent required evidence. No
package was installed, launched, replaced, or cleared, and no device data was
changed for this milestone.
